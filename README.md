# X Knowledge

A private, evidence-backed LLM wiki from freshly retrieved X likes and bookmarks.
This repository contains the reusable engine and synthetic tests only. Account
data, source captures, research, and wiki output belong outside the checkout.

Implementation follows the sequential [delivery plan](docs/PLAN.md). Each slice
requires automated checks and independent review before acceptance. Development
is in progress; synthetic checks do not establish live corpus completion.

See [domain terminology](CONTEXT.md) and [engineering rules](AGENTS.md).
